# Walkthrough - การแก้ไขปัญหาค่าพารามิเตอร์การจัดตำแหน่งตัวอักษร (LINE Flex Message API Bug Fix)

ขอบคุณประวัติการทำงาน (Debug Logs) จากอีเมลที่คุณกิตติศักดิ์ส่งมาให้ครับ! ถือว่าระบบส่งอีเมลฉุกเฉินที่เราทำไว้ทำงานได้มีประสิทธิภาพมาก ทำให้เราพบจุดผิดพลาดที่ชัดเจน 100% ทันทีโดยไม่ต้องเดาครับ

---

## 🔍 สาเหตุที่ LINE API แจ้งเตือนข้อผิดพลาด (Root Cause)

จากข้อมูล Log ที่แจ้งเตือน:
`{"message":"A message (messages[0]) in the request body is invalid","details":[{"message":"invalid property","property":"/body/contents/4/contents/0/contents/1/align"}]}`

*   **วิเคราะห์ปัญหา**: LINE ปฏิเสธค่าการจัดแนวอักษรที่ระบุว่า `"align": "right"` ในช่องแสดงผลแคลลอรี่อาหารแต่ละมื้อของตาราง
*   **คำอธิบาย**: ในมาตรฐาน LINE Flex Message รุ่นหลังๆ คุณสมบัติ `align` สำหรับองค์ประกอบอักษร (`text`) จะ **ไม่เปิดรับค่า `"left"` หรือ `"right"`** อีกต่อไป แต่ถูกแทนที่ด้วยมาตรฐานที่ยืดหยุ่นกว่าคือ:
    *   ใช้ **`"start"`** แทนการชิดซ้าย (Left)
    *   ใช้ **`"end"`** แทนการชิดขวา (Right)
    *   ใช้ **`"center"`** สำหรับการจัดกึ่งกลาง (Center)

เมื่อเราใส่ค่า `"align": "right"` ตัว LINE Messaging API จึงมองว่าข้อมูลไม่ถูกต้อง (Bad Request 400) และปฏิเสธการส่งข้อความนั้นกลับหาผู้ใช้ทันทีครับ

---

## 🛠️ วิธีการแก้ไข (The Fix)

ผมได้ทำการอัปเดตไฟล์ [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs) เรียบร้อยแล้ว โดยแก้ไขโค้ดบรรทัดที่เกิดปัญหาดังนี้:

```diff
- "align": "right",
+ "align": "end",
```

การเปลี่ยนมาใช้ค่าสากล `"align": "end"` จะส่งผลให้ข้อความตัวเลขแคลลอรี่ยังคงชิดขวาของตารางอย่างสวยงามตามเดิม และผ่านด่านตรวจความปลอดภัยของ LINE API ได้ 100% ครับ!

## 🚀 ขั้นตอนอัปเดตเพื่อเปิดใช้งาน:

1.  คัดลอกโค้ดทั้งหมดจากไฟล์ [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs) ล่าสุดบนคอมพิวเตอร์ของคุณ ไปวางบันทึกทับโค้ดเดิมในระบบ Apps Script Editor ของคุณ
2.  กด **Save (บันทึก)**
3.  กด **Deploy** -> **New deployment** -> เลือก Web app (Me / Anyone) -> กด **Deploy**
4.  นำ URL ใหม่ที่ได้ไปใส่แทนที่ Webhook ใน LINE Developers Console

เมื่ออัปเดตเสร็จแล้ว ลองพิมพ์อาหารและกดปุ่ม **"📊 สรุปแคลรวมวันนี้"** อีกครั้งหนึ่ง ตัวการ์ดรายงานสีกรมท่าจะส่งภาพและข้อมูลรายการสรุปตรงเข้าแชทอย่างราบรื่นร้อยเปอร์เซ็นต์แน่นอนครับ!
