# Walkthrough - การแก้ไขปัญหาระบบเลือกวันเกิดของปฏิทิน LINE (BirthDate Picker Bug Fix)

จากการทดสอบใช้งานจริงของคุณกิตติศักดิ์ พบปัญหาบั๊กเวลาผู้ใช้คลิกเลือกวันเกิด (เช่น `15/01/1988` บน LINE Desktop หรือ LINE ในบางอุปกรณ์) แล้วระบบเด้งข้อความแจ้งเตือนสีเทา `"ขออภัยค่ะ ระบบไม่พบข้อมูลวันเกิดที่เลือก..."`

---

## 🔍 สาเหตุหลักของบั๊ก (Root Cause)

1.  **พฤติกรรมและการส่งข้อมูลต่างกันของแต่ละ LINE Client**:
    *   ในโทรศัพท์มือถือระบบ iOS/Android ปุ่มปฏิทิน LINE Datetime Picker จะส่งผลลัพธ์กลับมาเป็นโครงสร้างมาตรฐานสากลคือ `event.postback.params.date` ในรูปแบบ `yyyy-MM-dd`
    *   แต่เมื่อใช้งานบน **LINE Desktop (LINE บนคอมพิวเตอร์ PC)** ดังภาพปฏิทินที่คุณกิตติศักดิ์ส่งมา ตัวโปรแกรม Desktop Client จะมีหน้าจอเลือกและกดปุ่ม `"Done"` ซึ่งส่งพารามิเตอร์วันเกิดกลับมาในรูปแบบภาษาถิ่นตามการตั้งค่าเครื่อง (เช่น `15/01/1988` แทนที่จะเป็น `1988-01-15`) และในบางกรณี ข้อมูลจะไม่ได้อยู่ในฟิลด์ `params.date` โดยตรง แต่ส่งมาในฟิลด์หรือคีย์อื่น
2.  **ความเข้มงวดในการแกะข้อมูล**:
    *   โค้ดเวอร์ชันแรกสุดทำการดึงเฉพาะเจาะจงที่คีย์ `event.postback.params.date` เท่านั้น เมื่อ LINE Desktop ส่งชื่อคีย์อื่นหรือฟอร์แมตต่างออกไป จึงทำให้ตัวแปรวันเกิดว่างเปล่า (`""`) และไม่ผ่านระบบสมัครสมาชิก

---

## 🛠️ วิธีการและจุดที่ทำการแก้ไข (The Fixes)

ผมได้พัฒนาโซลูชัน **ตัวแกะและสกัดวันเกิดอเนกประสงค์ (Multi-format Date Extractor)** ที่ปลอดภัยขั้นสูงสุด เพื่อมารับมือกับเรื่องนี้โดยเฉพาะครับ:

1.  **ฟังก์ชัน `extractBirthDate(event)` ใหม่**:
    *   **ดึงข้อมูลยืดหยุ่น**: หากคีย์มาตรฐาน `params.date` หรือ `params.datetime` ว่างเปล่า ฟังก์ชันจะทำการวนลูปค้นหาคีย์ใดๆ ก็ตามที่อยู่ในอ็อบเจกต์ `params` มาแทนที่โดยอัตโนมัติ
    *   **รองรับทุกฟอร์แมตวันที่**:
        *   รูปแบบ `yyyy-MM-dd` (เช่น `1988-01-15`)
        *   รูปแบบ `yyyy-MM-ddTHH:mm` (เช่น `1988-01-15T12:00`)
        *   **รูปแบบ `dd/MM/yyyy` (เช่น `15/01/1988` ตามหน้าจอ LINE PC ของคุณ)** โดยระบบจะแกะแยกชิ้น วัน, เดือน, ปี และประกอบย้อนหลังกลับมาเป็นมาตรฐานฐานข้อมูล `yyyy-MM-dd` คลีนๆ
        *   รูปแบบ `yyyy/MM/dd`
2.  **เชื่อมระบบแจ้งเตือนฉุกเฉินระดับสอง**:
    *   หากเกิดข้อผิดพลาดในการดึงวันเกิด ฟังก์ชันจะส่งเมลรายงาน Log ที่บรรจุ **โครงสร้าง JSON Webhook ของ LINE ดิบๆ ทั้งชิ้น** ส่งตรงไปยังอีเมลของคุณทันที ทำให้เราส่องดู Payload ดิบเพื่อแก้ปัญหาได้รวดเร็วขึ้นเป็นทวีคูณ
