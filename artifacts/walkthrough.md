# Walkthrough - ระบบคำนวณแคลลอรี่จำเพาะบุคคล (Personalized Calorie Limit & User Profiles)

การยกระดับโปรเจ็ค LINE Calories Chatbot ขึ้นสู่ขั้นถัดไปสำเร็จเรียบร้อยแล้วครับ! บอทของคุณกิตติศักดิ์ตอนนี้มีความสามารถในฐานะ "ที่ปรึกษาสุขภาพส่วนบุคคล" โดยจะจดจำเพศสภาพและอายุจริงของผู้ใช้งานเพื่อประเมินเกณฑ์แคลลอรี่จำเพาะบุคคล พร้อมวิเคราะห์ส่วนต่างพลังงานคงเหลือ/เกินประจำวันได้อย่างชาญฉลาด

---

## 🌟 ฟีเจอร์ที่เพิ่มเติมสำเร็จ

### 1. ระบบ Onboarding สุดล้ำ (ขั้นตอนสมัครสมาชิกจำลองแบบไร้รอยต่อ)
เมื่อผู้ใช้งานที่ไม่เคยมีประวัติส่งข้อความหาบอท ระบบจะส่งกล่องข้อความโต้ตอบอัตโนมัติ (Interactive Onboarding) ทันที:
*   **ขั้นตอนที่ 1 (ถามเพศสภาพ)**: ส่ง Flex Message ดีไซน์พรีเมียมสีม่วงหรูหรา ถามเพศสภาพ ให้คลิกปุ่ม **"เพศชาย 🧑"** หรือ **"เพศหญิง 👩"**
*   **ขั้นตอนที่ 2 (ถามวันเกิดด้วย LINE DatePicker)**: ส่ง Flex Message การ์ดขั้นตอนสุดท้ายที่มีปุ่ม **"📅 เลือกวันเกิดของคุณ"** 
    *   เมื่อผู้ใช้คลิกปุ่มนี้ ปฏิทินแบบ Native ของแอป LINE (LINE DatePicker) จะเด้งขึ้นมาให้เลือกวัน เดือน ปีเกิดโดยอัตโนมัติ ป้องกันความผิดพลาดในการพิมพ์คลาดเคลื่อน
*   **ยินดีต้อนรับ (Welcome Card)**: เมื่อเลือกวันเกิดสำเร็จ ระบบจะคำนวณอายุจริง คำนวณขีดจำกัดแคลลอรี่สูงสุดของคนนั้นตามเกณฑ์แพทย์ และบันทึกข้อมูลทั้งหมดลงฐานข้อมูล Google Sheets ทันที พร้อมแสดงการ์ดต้อนรับสีเขียวสดใสแสดงโควต้าแคลลอรี่ของผู้นั้นอย่างสวยงาม

### 2. สูตรประเมิน Max Calories จำเพาะบุคคล (ตารางแพทย์แม่นยำ 100%)
ฟังก์ชัน `getMaxCalories(age, gender)` ได้รับการจัดรูปแบบเพื่อถอดสูตรคำนวณจากตารางช่วงอายุและเพศสภาพที่คุณกิตติศักดิ์ระบุมาอย่างละเอียด:
*   **เด็กเล็ก (4-8 ปี)**: ชาย = 1,400 kcal | หญิง = 1,200 kcal
*   **เด็กโต (9-13 ปี)**: ชาย = 1,800 kcal | หญิง = 1,600 kcal
*   **วัยรุ่น (14-18 ปี)**: ชาย = 2,200 kcal | หญิง = 1,800 kcal
*   **ทำงานตอนต้น (19-30 ปี)**: ชาย = 2,400 kcal | หญิง = 2,000 kcal
*   **ทำงานตอนกลาง (31-50 ปี)**: ชาย = 2,200 kcal | หญิง = 1,800 kcal
*   **ผู้ใหญ่ตอนปลาย (51 ปีขึ้นไป)**: ชาย = 2,000 kcal | หญิง = 1,600 kcal

### 3. ตารางสรุปแคลสะสมและส่วนต่างคงเหลือ/เกินรายวัน (`createSummaryFlex`)
เมื่อผู้ใช้งานถามว่า "วันนี้กินไปกี่แคล" การ์ดสรุปประวัติประจำวันจะดึงค่า `MaxCalories` ส่วนบุคคลมาคำนวณหักลบและแสดงผลอย่างสวยงาม:
*   🟢 **กรณีแคลลอรี่ยังไม่เกินเป้าหมาย (Remaining)**: ยอดตัวเลขแสดงผลเป็น **สีเขียว** พร้อมข้อความเตือนชัดเจน **"ยังทานได้อีก: XXX kcal"** เพื่อให้วางแผนทานมื้อถัดไปได้สนุกขึ้น
*   🔴 **กรณีแคลลอรี่ทะลุเป้าหมาย (Exceeded)**: ยอดตัวเลขและคำแนะนำจะเปลี่ยนเป็น **สีแดง** เตือนสติ และระบุข้อความ **"ทานเกินเป้าหมายไป: XXX kcal ⚠️"** เพื่อแนะแนวทางออกกำลังกายให้เบิร์นพลังงานส่วนเกินออก

## 🛠️ รายละเอียดโครงสร้างโค้ดที่อัปเดตใน [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs)

1.  **การดักรับ Event ประเภท Postback**:
    อัปเดต `doPost(e)` ให้คอยรองรับ Event ประเภท `postback` เพื่อรับส่งการโต้ตอบปุ่มและการยืนยันวันที่จากปฏิทินของ LINE
2.  **การแยกตารางเก็บข้อมูลโปรไฟล์ผู้ใช้**:
    *   ฟังก์ชัน `getUserProfile(userId)`: ตรวจเช็คประวัติในตารางชีต `UserProfiles`
    *   ฟังก์ชัน `saveUserProfile(userId, birthDate, gender)`: บันทึกข้อมูลส่วนบุคคลลงตารางแถวใหม่สำเร็จพร้อมเวลาลงทะเบียนประเทศไทย
3.  **ฟังก์ชันสุขภาพส่วนบุคคล**:
    *   `calculateAge(birthDateStr)`: วิเคราะห์หาอายุจริงของผู้ใช้อัตโนมัติ
    *   `getMaxCalories(age, gender)`: เลือกเป้าหมายแคลลอรี่ที่เหมาะสมทางสรีรวิทยา
4.  **Flex Message Templates ใหม่**:
    *   `askGenderFlex()`: โครงสร้างการ์ดถามเพศสภาพ
    *   `askBirthDateFlex(gender)`: โครงสร้างการ์ดถามวันเกิด (บรรจุ Action `datetimepicker`)
    *   `welcomeProfileFlex(age, gender, maxCalories)`: การ์ดแจ้งสำเร็จโปรไฟล์

## 🚀 ขั้นตอนติดตั้งตารางและทดสอบระบบบนเครื่องใหม่

ก่อนทดสอบใช้งานจริง คุณกิตติศักดิ์ต้องดำเนินการใน Google Sheet และ Deploy สคริปต์ดังนี้ครับ:

### ขั้นตอนที่ 1: เพิ่มตารางประวัติโปรไฟล์ใน Google Sheet **[สำคัญ 🌟]**
1.  เปิด Google Sheet ของคุณขึ้นมา
2.  กดเพิ่มแท็บที่ 2 ด้านล่าง ตั้งชื่อแท็บแผ่นงานว่า **`UserProfiles`**
3.  พิมพ์ชื่อหัวคอลัมน์ในแถวแรก (แถวที่ 1 คอลัมน์ A ถึง D) ตามลำดับ:
    *   คอลัมน์ A: `UserID`
    *   คอลัมน์ B: `BirthDate`
    *   คอลัมน์ C: `Gender`
    *   คอลัมน์ D: `RegisteredAt`

### ขั้นตอนที่ 2: Deploy และอัปเดต Webhook
1.  คัดลอกโค้ดทั้งหมดจากไฟล์ [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs) ล่าสุดไปบันทึกทับใน Apps Script Editor
2.  กด **Save**
3.  กด **Deploy (การทำงานใช้จริง)** -> **New deployment (การทำงานใช้จริงรายการใหม่)**
4.  ตรวจสอบการตั้งค่า (Execute as: Me / Who has access: Anyone) แล้วกดปุ่ม **Deploy**
5.  นำ URL ของ Web app ตัวใหม่ไปอัปเดตแทนที่ Webhook เดิมใน LINE Developers และกดเปิดสวิตช์ Webhook

## 🧪 ขั้นตอนการทดสอบฟีเจอร์ใช้งาน (Verification & Testing)

คุณสามารถเปิดแชท LINE เพื่อพิสูจน์การทำงานของระบบใหม่ได้ทันทีครับ:

1.  **ทดสอบการสมัครสมาชิก (Onboarding)**:
    *   ลองพิมพ์ชื่อเมนูอาหารส่งหาบอท หรือ พิมพ์ขอสรุปผลสะสม เช่น `"วันนี้กินไปกี่แคล"`
    *   **ผลลัพธ์**: บอทจะตรวจพบว่า User ID ของคุณยังไม่มีประวัติในชีต `UserProfiles` จึงส่งการ์ดสีม่วงถามเพศสภาพมาทันที
    *   **การทดสอบ**: คลิกปุ่ม **"เพศชาย 🧑"** หรือ **"เพศหญิง 👩"** -> บอทจะตอบกลับเป็นการ์ดขั้นตอนที่สอง
    *   **การทดสอบปฏิทิน**: คลิกปุ่ม **"📅 เลือกวันเกิดของคุณ"** -> ปฏิทิน Native ของแอป LINE จะเด้งขึ้นมา ให้เลือกวัน เดือน ปีเกิดของคุณแล้วกดตกลง
    *   **ผลการลงทะเบียน**: บอทจะส่งการ์ดต้อนรับระบุคำนวณอายุและเป้าหมายพลังงานสำเร็จ! และใน Google Sheet แท็บ `UserProfiles` จะต้องปรากฏแถวข้อมูล UserID, วันเกิด, เพศ และเวลาสมัครถูกต้องครบถ้วน!
2.  **ทดสอบแคลลอรี่จำเพาะบุคคลและรายงานส่วนต่าง**:
    *   พิมพ์อาหารเพิ่ม เช่น `"ต้มยำปลากระพง"` (250 kcal)
    *   พิมพ์ถามบอทว่า `"วันนี้กินไปกี่แคล"`
    *   **ผลลัพธ์**: บอทจะตอบกลับเป็นการ์ดสรุปสะสมสีน้ำเงินเข้มขรึม โดยจะแสดงตัวเลขแคลลอรี่รวมที่สะสม (เช่น `250`) และคำนวณพลังงานส่วนต่างคงเหลือแสดงเป็น **สีเขียว** เด่นชัดตรงกรอบคำแนะนำด้านล่างว่า **"🟢 ยังทานได้อีก XXX kcal"** พร้อมสูตรโภชนาการส่วนบุคคลของคุณกิตติศักดิ์อย่างหรูหราพรีเมียมครับ!
