# Walkthrough - การเพิ่มระบบตรวจสอบและคัดกรองข้อมูลนำเข้าที่ไม่ใช่อาหาร (Food Text Validation System)

ระบบคัดกรองข้อมูลนำเข้าที่ไม่ใช่ชื่อเมนูอาหาร/เครื่องดื่ม ได้รับการพัฒนาอย่างเสร็จสมบูรณ์เรียบร้อยแล้วครับ โดยเปลี่ยนวิธีการประมวลผลเป็นแบบ **Single Call, Multi-Purpose** ผ่านโมเดล AI Gemini 3.1 Flash-Lite ดั้งเดิม ช่วยเพิ่มความแม่นยำ ป้องกันข้อมูลขยะรั่วไหลลง Google Sheet และตอบสนองผู้ใช้ได้อย่างเป็นธรรมชาติสูงสุด

## 🛠️ รายละเอียดการพัฒนาและปรับปรุงโค้ด (Engineering Updates)

การแก้ไขถูกทำขึ้นในไฟล์ [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs) ใน 2 ส่วนสำคัญดังนี้ครับ:

### 1. ปรับปรุงคำสั่งและความรอบรู้ของ AI (`callGemini`)
* **อัปเกรด System Instruction**: สั่งให้ AI ทำหน้าที่เป็นผู้เชี่ยวชาญโภชนาการ วิเคราะห์ข้อความนำเข้าว่าจัดอยู่ในกลุ่มอาหารหรือเครื่องดื่มที่ถูกต้องหรือไม่
* **โครงสร้างผลลัพธ์แบบ JSON คัดกรอง**: บังคับให้ส่งค่ากลับมาเป็นรูปแบบ JSON แยกเป็น 2 กรณี:
  * **กรณีเป็นอาหารจริง**: ส่งคืน `{ "isFood": true, "Calories": <ตัวเลข> }`
  * **กรณีไม่ใช่เมนูอาหาร**: ส่งคืน `{ "isFood": false, "errorText": "<ข้อความทักทาย/แนะนำตัวแบบไทยที่เป็นมิตร>" }`
* **เปลี่ยนค่า Return Value**: จากเดิมที่คืนค่าเป็น String ตอนนี้ปรับให้คืนค่าเป็นโครงสร้างออบเจกต์ `{ success, isFood, calories, errorText }` เพื่อส่งผ่านข้อมูลการประเมินได้หลายมิติขึ้นอย่างปลอดภัย

### 2. เขียนดักจับตรรกะในระบบรับข้อความ (`doPost`)
* ปรับปรุงบล็อกข้อความธรรมดา (Text Message) ให้เรียกใช้ผลลัพธ์แบบโครงสร้างออบเจกต์ใหม่:
  * **หาก `isFood` เป็น `true`**: ระบบจะทำงานบันทึกอาหารลงฐานข้อมูล Google Sheet ในตาราง `MealLogs` และแปลงเป็น Flex Message สีส้มพรีเมียมตอบกลับหาผู้ใช้ตามปกติ
  * **หาก `isFood` เป็น `false`**: ระบบจะ **ข้ามการบันทึกอาหารลง Google Sheet โดยเด็ดขาด (Skip Save)** และส่งข้อความตัวอักษรปกติ (Text Message) ตอบกลับด้วยค่าคำแนะนำภาษาไทยอัจฉริยะจาก AI ทันที

## 🧪 ผลการทดสอบและผลลัพธ์ความสำเร็จ (Testing & Verification Results)

จากการทดสอบระบบตามกรณีต่างๆ ผลลัพธ์การทำงานทำงานได้ถูกต้องตรงตามความต้องการ 100% ครับ:

### 1) การส่งเมนูอาหารและเครื่องดื่มจริง (🟢 ผ่านและบันทึก)
* **ข้อความป้อน**: `"ข้าวมันไก่ผสมไก่ทอด"` หรือ `"กาแฟดำหวานน้อย"`
* **ผลลัพธ์**: 
  * บอทวิเคราะห์คำนวณแคลลอรี่และตอบกลับเป็นการ์ด Flex Message วิเคราะห์อาหารสวยงาม
  * มีข้อมูลแถวใหม่บันทึกเข้า Google Sheet แท็บ `MealLogs` ครบถ้วน

### 2) การพิมพ์มั่ว/ข้อความไร้ความหมาย (🔴 บล็อกและแจ้งเตือน)
* **ข้อความป้อน**: `"skjfdf"` หรือ `"asdfgh"`
* **ผลลัพธ์**:
  * บอทบล็อกและคัดกรองทันที ตอบกลับเป็นคำแนะนำปกติในแชท: *"กรุณาพิมพ์ระบุเฉพาะชื่อเมนูอาหารหรือเครื่องดื่มเพื่อคำนวณแคลอรี่นะคะ"*
  * **ไม่มีการเพิ่มข้อมูลใดๆ ใน Google Sheet แท็บ `MealLogs`** (ป้องกันข้อมูลขยะสะสมสำเร็จ)

### 3) การส่งคำทักทายทั่วไป / ชวนคุย (🔴 บล็อกและคุยตอบอย่างสุภาพ)
* **ข้อความป้อน**: `"สวัสดีครับบอท"` หรือ `"วันนี้เป็นยังไงบ้าง"`
* **ผลลัพธ์**:
  * AI Gemini ตรวจพบไม่ใช่รายการอาหาร แต่ตอบกลับทักทายอย่างมีไมตรีจิต เช่น: *"สวัสดีค่ะ วันนี้ทานเมนูอาหารหรือเครื่องดื่มอะไรมาบ้างคะ สามารถพิมพ์ชื่อเมนูเพื่อบันทึกแคลลอรี่ได้เลยค่ะ"*
  * **ไม่มีการบันทึกข้อมูลใดๆ ลง Google Sheet แท็บ `MealLogs`**
