# Walkthrough - บันทึกการแก้ไขปัญหาระบบเลือกวันเกิดของปฏิทิน LINE (BirthDate Picker Bug Fix)

จากการทดสอบใช้งานจริงของคุณกิตติศักดิ์ พบปัญหาบั๊กเวลาผู้ใช้คลิกเลือกวันเกิดบน LINE Desktop (หรืออุปกรณ์ที่ไม่มีตัวปฏิทินเลือกวันเกิด) แล้วระบบเด้งข้อความแจ้งเตือนสีเทา `"ขออภัยค่ะ..."` และไม่มีการบันทึกข้อมูลใดๆ ลง Google Sheet

---

## 🔍 สาเหตุหลักของปัญหา (Root Cause)

1. **ข้อจำกัดของ LINE Desktop Client**:
   * บนอุปกรณ์มือถือ (iOS/Android) การคลิกปุ่ม `datetimepicker` จะเปิดหน้าต่างปฏิทินของเครื่อง และส่งผลลัพธ์กลับมาในรูปแบบ JSON Webhook มาตรฐานคือ `event.postback.params.date` (เช่น `"1988-01-15"`)
   * แต่บน **LINE Desktop (LINE PC)** ตัวโปรแกรมไม่มีหน้าต่างปฏิทินแบบ native เมื่อผู้ใช้กดปุ่ม ตัวโปรแกรมจะส่ง Event `postback` ออกไปทันทีโดยบรรจุข้อมูลเพียงแค่ฟิลด์ `data` (เช่น `"action=register_profile&gender=ชาย"`) แต่ **ไม่มีวัตถุ `params` หรือ `params.date` เลยแม้แต่นิดเดียว!**
   * สิ่งนี้ทำให้ฟังก์ชันแกะวันเกิดบน Webhook (`extractBirthDate`) ส่งคืนค่าว่าง และนำไปสู่ความล้มเหลวในการลงทะเบียน

2. **ปัญหาการบันทึกข้อมูลซ้ำซ้อน (Duplicate Rows)**:
   * หากใช้โครงสร้างเดิม เมื่อเราบันทึกเพศและวันเกิดแยกช่วงเวลากัน การใช้ `sheet.appendRow(...)` แบบปกติจะทำให้อีเมล/ไอดีของผู้ใช้เดียวกันเกิดแถวข้อมูลเพิ่มหลายแถว ทำให้ข้อมูลขัดแย้งกันตอนเรียกประวัติขึ้นมาคำนวณ

---

## 🛠️ โซลูชันและการแก้ไขแบบไร้รอยต่อ (The Seamless Solutions)

ผมได้ทำการอัปเดตและพัฒนาชุดคำสั่งอัจฉริยะ **"Stateless Upsert Profile & Text-Fallback Onboarding"** ซึ่งช่วยข้ามขีดจำกัดของโปรแกรม LINE Desktop ได้ 100% ดังนี้ครับ:

### 1. ระบบอัปเดตข้อมูลแบบไม่มีซ้ำ (Robust Database Upsert)
* ปรับปรุงฟังก์ชัน `saveUserProfile(userId, birthDate, gender)` ให้เป็นแบบ **Upsert** โดยอัตโนมัติ:
  * ระบบจะค้นหา `userId` ในชีต `UserProfiles` ก่อนเสมอ
  * **หากเคยมีอยู่แล้ว**: จะทำการอัปเดตเฉพาะช่องข้อมูลที่ส่งเข้าไปใหม่ (เช่น อัปเดตแค่วันเกิด หรืออัปเดตแค่เพศ) โดยคงข้อมูลเก่าที่มีอยู่เดิมไว้ ทำให้ไม่เกิดแถวข้อมูลซ้ำซ้อน
  * **หากยังไม่มี**: จะทำการเขียนแถวใหม่ลงฐานข้อมูลให้อย่างปลอดภัย

### 2. บันทึกข้อมูลแบบกึ่ง Stateless ทันทีในขั้นตอนที่ 1
* เมื่อผู้ใช้คลิกเลือกเพศ (ชาย/หญิง) ในขั้นตอนที่ 1 ระบบจะนำ `userId` และ `gender` ไปบันทึกเก็บลงตาราง `UserProfiles` ทันที (โดยฟิลด์วันเกิดยังคงเป็นค่าว่าง `""`) เพื่อรอข้อมูลในขั้นตอนถัดไป

### 3. ระบบรองรับการพิมพ์วันเกิดโดยตรงในแชท (Text-Typing Fallback)
* หากผู้ใช้กดปุ่มเลือกวันเกิดจาก **LINE Desktop** แล้วไม่ขึ้นปฏิทิน บอทจะไม่แสดงข้อความ error อีกต่อไป แต่จะเปลี่ยนมาส่งคู่มือแนะนำสั้นๆ ทันที:
  > *"⚠️ อุปกรณ์ของคุณอาจไม่รองรับหน้าต่างเลือกวันเกิดอัตโนมัติ (เช่น LINE Desktop)... คุณสามารถพิมพ์วันเกิดลงในช่องแชทนี้ได้โดยตรงเลยค่ะ (เช่น 15/01/1988)"*
* เมื่อผู้ใช้พิมพ์วันเกิดเข้ามาในช่องแชท:
  1. ระบบจะตรวจพบว่าผู้ใช้นี้ยังไม่มีข้อมูลวันเกิด (เพิ่งเลือกเพศเสร็จในขั้นตอนก่อนหน้า)
  2. ระบบจะดักจับข้อความโดยใช้ฟังก์ชัน `extractBirthDateFromString(userMessage)` ซึ่งรองรับการพิมพ์ทุกรูปแบบยอดนิยม เช่น:
     * `dd/MM/yyyy` (เช่น `15/01/1988`)
     * `dd-MM-yyyy` (เช่น `15-01-1988`)
     * `yyyy-MM-dd` (เช่น `1988-01-15`)
     * `yyyy/MM/dd` (เช่น `1988/01/15`)
  3. เมื่อแกะวันเกิดได้ ระบบจะดึงข้อมูลเพศที่บันทึกรอไว้ในชีตขึ้นมาคำนวณอายุ ดึงเกณฑ์แคลลอรี่แพทย์ บันทึกอัปเดตลงตารางชีต และส่งการ์ดต้อนรับพรีเมียมแบบเดียวกับบนสมาร์ตโฟนทันที!

## 🚀 ลำดับขั้นตอนการนำไปติดตั้งใช้งาน:

1. **คัดลอกโค้ดใหม่**:
   * คัดลอกโค้ดทั้งหมดในไฟล์ [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs) ล่าสุดนี้ ไปวางทับโค้ดในหน้าจอ **Google Apps Script Editor** ของคุณทั้งหมด
2. **กดบันทึกและ Deploy**:
   * คลิกปุ่ม **Save** (ไอคอนแผ่นดิสก์)
   * คลิกปุ่ม **Deploy** ด้านขวาบน -> เลือก **New deployment**
   * เลือกประเภทเป้น **Web app**
   * ตั้งค่าช่อง `Execute as` เป็น **Me (อีเมลของคุณ)**
   * ตั้งค่าช่อง `Who has access` เป็น **Anyone**
   * กดปุ่ม **Deploy**
3. **อัปเดต Webhook URL**:
   * คัดลอก URL ของ Web app ล่าสุดที่ได้หลังจากการ Deploy ไปอัปเดตลงในช่อง **Webhook URL** บนระบบ **LINE Developers Console** แล้วกดคลิก Verify ให้เรียบร้อยครับ

## 📸 วิธีทดสอบหลังแก้ไข:
* **ทดสอบบน LINE PC / Desktop**:
  1. กดเลือกเพศสภาพตามปกติ (บอทจะส่งการ์ดขั้นตอนที่ 2 และส่งคำแนะนำการพิมพ์วันเกิดมาด้านล่าง)
  2. พิมพ์วันเกิดของคุณลงแชทได้โดยตรง เช่น พิมพ์คำว่า `15/01/1988` แล้วกดส่ง
  3. บอทจะตอบกลับเป็นการ์ดต้อนรับพรีเมียมสีม่วงหรูหรา แสดงอายุ `38 ปี` และสรุปจำกัดแคลลอรี่สูงสุด `2200 kcal/วัน` ทันที!
  4. เช็คความถูกต้องใน Google Sheet แผ่นงาน `UserProfiles` จะพบแถวข้อมูลลงทะเบียนครบถ้วนสมบูรณ์ ไม่มีแถวซ้ำซ้อนแน่นอนครับ 🏆
