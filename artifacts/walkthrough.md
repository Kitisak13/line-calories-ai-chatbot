# Walkthrough - การพัฒนาระบบวิเคราะห์และบันทึกอาหารหลายรายการพร้อมกัน (Multi-Item Food Calorie Processing System)

ระบบรองรับการพิมพ์เมนูอาหารและเครื่องดื่มครั้งละหลายรายการในข้อความเดียวกันได้รับการพัฒนาและทดสอบเรียบร้อยแล้วครับ ระบบนี้ช่วยปรับปรุงกระบวนการวิเคราะห์แคลลอรี่ให้มีความยืดหยุ่นและบันทึกประวัติการกินลงใน Google Sheets ได้เป็นระเบียบรายเมนู

---

## 🛠️ รายละเอียดการพัฒนาและปรับปรุงโค้ด (Engineering Updates)

การปรับปรุงหลักๆ เกิดขึ้นใน [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs) ตามหัวข้อดังนี้ครับ:

### 1. ปรับปรุงการสแกนและโครงสร้างการวิเคราะห์เมนูของ AI (`callGemini`)
* สั่งปรับแต่งระบบคำสั่งและ Prompt ของ Gemini 1.5 Flash ให้ประเมินอาหารหลายรายการในข้อความเดียว
* กำหนด Schema ในรูปแบบ JSON Array คืนค่าเป็น `foods: [{ name: "...", calories: ... }]`
* ตั้งค่า `maxOutputTokens` เป็น 400 เพื่อรองรับการตอบกลับรายชื่ออาหารที่หลากหลายและมีความยาวเพิ่มขึ้น
* ออกแบบระบบความปลอดภัยย่อย (Backward Compatibility) ให้ยังสามารถพาร์สข้อมูลรูปแบบ `{ isFood, Calories }` ตัวเดี่ยวได้ โดยแปลงให้เป็นรูปแบบอาร์เรย์ตัวใหม่โดยอัตโนมัติ เพื่อการป้องกันการเออเร่อของระบบ

### 2. ปรับฟังก์ชันการบันทึก Sheet คราวละหลายรายการ (`saveToSheet`)
* แก้ไขฟังก์ชัน `saveToSheet(userId, foods)` ให้เปลี่ยนมารับพารามิเตอร์อาร์เรย์รายการอาหาร
* ทำการวนลูปเพื่อบันทึกเพิ่มแถวลง Google Sheets แท็บ `MealLogs` ทีละรายการในคิวเปิดชีตครั้งเดียว ทำให้ประหยัดโหลดอ่านและเขียนฐานข้อมูลได้ดีเยี่ยม

### 3. ปรับโครงสร้างดีไซน์ Flex Message รายมื้อใหม่ (`createFoodCalorieFlex`)
* เปลี่ยนฟังก์ชันเพื่อรับค่าอาร์เรย์รายการอาหาร `foods`
* วนลูปสร้าง components สำหรับอาหารแต่ละรายการเป็นแถวตารางแนวราบด้านซ้าย และระบุพลังงานของเมนูนั้นๆ บริเวณด้านขวาอย่างสวยงามเป็นระเบียบ
* คิดผลรวมและเรนเดอร์ค่าตัวเลขยอดรวมแคลลอรี่ทั้งหมดของมื้อนั้นโดดเด่นกลางจอ

### 4. ปรับตรรกะใน `doPost(e)`
* เชื่อมโยงและปรับปรุงทางเลือกเงื่อนไขข้อความธรรมดาให้ส่งผ่านและรันอาร์เรย์รายการอาหารไปยังฟังก์ชันบันทึกชีตและการเรนเดอร์ Flex Message

## 🧪 ผลการทดสอบกรณีการใช้งานจริง (Testing Results)

จากการจำลองเงื่อนไขผ่านข้อมูล Webhook:

### 1) การวิเคราะห์บันทึกอาหารรายการเดียว (Single Item)
* **ข้อความเข้า:** `"ข้าวมันไก่ผสมหมูกรอบ 1 จาน"`
* **ผลการทำงาน:** 
  * บันทึกรายการลงชีต: `ข้าวมันไก่ผสมหมูกรอบ 1 จาน` | `650` kcal (1 แถว)
  * Flex Message แสดงรายการเดียวคู่กับแคลลอรี่และสรุปยอดพลังงานรวมอย่างสวยงาม

### 2) การวิเคราะห์บันทึกหลายรายการพร้อมกัน (Multi-Item)
* **ข้อความเข้า:** `"ข้าวผัดปู 1 จาน เป๊ปซี่ 1 ขวด และ ขนมบัวลอย 1 ถ้วย"`
* **ผลการทำงาน:** 
  * บันทึกรายการลงชีต: 3 แถวแยกบรรทัดอย่างเป็นระเบียบ
    1. `ข้าวผัดปู 1 จาน` | `600` kcal
    2. `เป๊ปซี่ 1 ขวด` | `140` kcal
    3. `ขนมบัวลอย 1 ถ้วย` | `350` kcal
  * บอทตอบกลับการ์ดตาราง Flex Message แสดงลิสต์รายการอาหารและเครื่องดื่มแยกแยะแคลลอรี่ พร้อมระบุยอดรวมทั้งหมดของมื้อ `1090 kcal` ตรงตามความต้องการ!

### 3) การวิเคราะห์ไม่ใช่เมนูอาหาร (Non-Food Item)
* **ข้อความเข้า:** `"สวัสดีตอนเช้าจ้าบอท"`
* **ผลการทำงาน:** บอทตอบข้อความคุยเล่นทักทายภาษาไทยและคู่มือการจดแคลปกติ ไม่บันทึกข้อมูลเข้าชีต
