# แผนงานระบบกล่องข้อความพรีเมียม (LINE Flex Messages Integration)

แผนการพัฒนานี้จะอัปเกรดการตอบกลับของ LINE Calories Chatbot จากข้อความตัวอักษรธรรมดา (Plain Text) ให้กลายเป็น **Flex Messages** ซึ่งมีหน้าตาการแสดงผลแบบการ์ดพรีเมียม สีสันสวยงาม และมีโครงสร้างตอบรับที่ใช้งานง่าย (Interactive UI) 

---

## รูปแบบดีไซน์ Flex Messages ที่ออกแบบไว้

เราจะแบ่งการ์ดแสดงผลออกเป็น 2 รูปแบบหลักๆ ดังนี้ครับ:

### 1. การ์ดรายงานแคลลอรี่อาหารรายเมนู (Single Food Calorie Card)
เมื่อผู้ใช้ถามเมนูอาหารใหม่ (เช่น "กุ้งย่าง 5 ตัว") บอทจะตอบกลับด้วยกล่อง Flex Message ดีไซน์พรีเมียม:
*   **Header**: สี Gradient ส้ม-ชมพูระเรื่อ ระบุว่า "วิเคราะห์สำเร็จ! 🤖"
*   **Body**: แสดงชื่อเมนูอาหารตัวใหญ่เด่นชัด (เช่น **กุ้งย่าง 5 ตัว**) และตัวเลขปริมาณแคลลอรี่แบบเน้นย้ำ **"150 kcal"**
*   **Footer**: เพิ่มปุ่มกด **"📊 สรุปแคลวันนี้"** แบบสวยงาม เมื่อคลิกปุ่มนี้จะส่งข้อความหาบอทอัตโนมัติว่า "สรุปแคลวันนี้" (ใช้งานง่ายโดยไม่ต้องพิมพ์เอง)

### 2. การ์ดสรุปยอดแคลลอรี่สะสมรายวัน (Today's Calorie Summary Card)
เมื่อผู้ใช้ถามว่า "วันนี้กินไปกี่แคล" บอทจะแสดงการ์ดสรุปประวัติ:
*   **Header**: สี Gradient น้ำเงิน-ม่วงหรูหรา ระบุว่า "รายงานแคลสะสมวันนี้ 🍽️"
*   **Body**: 
    *   แสดงตัวเลขแคลรวมวันนี้ตัวใหญ่มาก เช่น **"700 kcal"** พร้อมแถบสถานะหรือข้อความโภชนาการแบบไดนามิก
    *   มีรายการอาหารที่กินไปทั้งหมดของวันแยกย่อยแสดงเป็นตารางแถวชัดเจน (เช่น `1. ผัดไทยกุ้งสด (600 kcal)`, `2. ชานม (100 kcal)`)
*   **Footer**: คำแนะนำโภชนาการแบบไดนามิกตามช่วงพลังงานที่ได้รับในวันนี้

## ขั้นตอนการทำงาน (Implementation Plan)

### 1. การปรับปรุงฟังก์ชันการส่งข้อความ (`replyLineMessage`)
ปรับปรุงให้ฟังก์ชัน `replyLineMessage(replyToken, messageContent)` สามารถรองรับข้อมูลอินพุตได้ทั้งแบบ **ตัวอักษรธรรมดา (String)** และ **วัตถุข้อความของ LINE (Object/Flex Message)** อย่างราบรื่นและยืดหยุ่น:
```javascript
let messages = [];
if (typeof messageContent === "object") {
  messages = [messageContent]; // ส่งตรงเป็นวัตถุ Flex Message
} else {
  messages = [{ type: "text", text: messageContent }]; // ส่งแบบ Text ธรรมดา
}
```

### 2. ฟังก์ชันช่วยสร้างกล่องข้อความเดี่ยว `createFoodCalorieFlex(foodMenu, calories)`
สร้างฟังก์ชันช่วยประกอบโครงสร้าง JSON ของ Flex Message สำหรับมื้ออาหารเดี่ยว โดยอิงดีไซน์โมเดิร์นและสะดุดตา

### 3. ฟังก์ชันช่วยสร้างกล่องสรุปรายวัน `createSummaryFlex(todayMeals, totalCalories)`
สร้างฟังก์ชันประมวลผลประวัติอาหาร และประกอบเข้ากับ JSON Flex Message ในรูปแบบตารางแจกแจงรายการรายวัน โดยมีการคำนวณดีไซน์แบบไดนามิก

## แผนการทดสอบ (Verification Plan)

### การทดสอบแบบ Manual
1.  **ทดสอบการส่งเมนูอาหาร**: พิมพ์ "กุ้งย่าง 5 ตัว" -> ตรวจสอบว่าผลลัพธ์ส่งกลับมาในลักษณะบับเบิ้ล (Bubble Card) ที่มีปุ่มกดด้านล่างอย่างสวยงาม
2.  **ทดสอบปุ่ม Action**: กดปุ่ม "📊 สรุปแคลวันนี้" ที่การ์ด -> ตรวจสอบว่าระบบส่งสรุปแคลลอรี่รายวันกลับมาอย่างรวดเร็ว
3.  **ทดสอบการสรุปรายวัน**: ตรวจสอบโครงสร้างตารางแสดงผลของการ์ดรายวันว่าลิสต์รายการถูกต้อง มีสีสันสวยงามและตัวหนังสือจัดตำแหน่งสมดุลดี
