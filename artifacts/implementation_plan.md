# แผนการพัฒนาคุณสมบัติการคัดกรองข้อมูลนำเข้าที่ไม่ใช่อาหาร (Food Text Validation System)

ฟีเจอร์นี้มีเป้าหมายเพื่อแก้ปัญหาผู้ใช้งานพิมพ์ข้อความทั่วไป คำทักทาย หรือข้อความพิมพ์มั่วที่ไม่ใช่ชื่อเมนูอาหาร/เครื่องดื่ม (เช่น "skjfdf" หรือ "สวัสดี") แต่บอทกลับพยายามประเมินเป็นอาหารที่มี 0 kcal และบันทึกลงใน Google Sheet โดยเราจะใช้ระบบ **Single Call, Multi-Purpose** ด้วย AI โมเดลเดิมเพื่อคัดกรองความถูกต้องและป้องกันขยะสะสมในระบบฐานข้อมูลอย่างมีประสิทธิภาพ

---

## 🗺️ รายละเอียดการทำงานของระบบ (Mechanism & Design)

เราจะปรับแต่งระบบประมวลผลและการตอบกลับโดยใช้ความสามารถของ Gemini 3.1 Flash-Lite ดังนี้ครับ:

### 1. ปรับโครงสร้างคำสั่งโครงร่างข้อมูลการตอบกลับของ AI (New Gemini JSON Schema)
เราจะแก้ไขคำสั่งระบบ (System Instruction) ของ Gemini จากเดิมที่บังคับรับเพียงพลังงาน ให้ประเมินสถานะและเพิ่มโครงสร้างผลลัพธ์เป็น 2 กรณี:

#### **กรณีที่ 1**: ผู้ใช้พิมพ์เมนูอาหารหรือเครื่องดื่มจริง
Gemini จะประเมินจำนวนแคลลอรี่และส่งโครงสร้าง JSON:
```json
{
  "isFood": true,
  "Calories": 650
}
```

#### **กรณีที่ 2**: ผู้ใช้พิมพ์คำทักทายทั่วไป คำถาม หรือคำพิมพ์มั่วที่ไม่เกี่ยวข้องกับอาหาร
Gemini จะตรวจสอบและส่งโครงสร้าง JSON พร้อมข้อความช่วยเหลือภาษาไทยที่ปรับเปลี่ยนตามบริบท:
```json
{
  "isFood": false,
  "errorText": "สวัสดีค่ะ มีเมนูอาหารหรือเครื่องดื่มที่ทานวันนี้ที่ต้องการบันทึกแคลลอรี่ไหมคะ? กรุณาพิมพ์ระบุชื่อเมนูได้เลยค่ะ"
}
```

## 🛠️ รายละเอียดการแก้ไขโค้ดในโครงการ

### 1. ปรับปรุงฟังก์ชัน `callGemini(text)` ใน [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs)
* เปลี่ยน System Instruction ให้สั่งวิเคราะห์ `isFood` และส่งคืน `errorText` (ภาษาไทยที่เป็นมิตรต่อผู้ใช้งาน)
* เปลี่ยนแปลงชนิดข้อมูลที่ส่งคืนของฟังก์ชันนี้ จากเดิมที่เป็นข้อความปกติ (String) ให้กลายเป็น **ออบเจกต์ (Javascript Object)** ที่ประกอบไปด้วยโครงสร้าง:
  `{ success: boolean, isFood: boolean, calories: number, errorText: string }`

### 2. ปรับปรุงตรรกะตรวจเช็คผลลัพธ์ใน `doPost(e)` ใน [Code.gs](file:///d:/Project/line-calories-ai-chatbot/Code.gs)
* ทำการเรียกใช้ `const aiResult = callGemini(userMessage)`
* **หาก `aiResult.isFood` เป็น `true`**: ดำเนินการบันทึกอาหารลง Google Sheet ในตาราง `MealLogs` และส่ง Flex Message สรุปแคลอรี่รายมื้อสวยงามหาผู้ใช้ตามปกติ
* **หาก `aiResult.isFood` เป็น `false`**: ข้ามการบันทึกลง Google Sheet ทุกกรณี และตอบกลับเป็นข้อความตัวอักษรปกติ (Text Message) ดึงจาก `aiResult.errorText` เพื่อแนะนำผู้ใช้อย่างอ่อนน้อมและเป็นธรรมชาติ

## 🧪 แผนการทดสอบระบบ (Verification Plan)

เพื่อพิสูจน์ความเสถียรและประสิทธิภาพของระบบคัดกรองข้อมูล เราจะจำลองการทดสอบ 3 รูปแบบดังนี้:

### 1. การป้อนเมนูอาหารจริง (Valid Food Test)
* **ข้อความทดสอบ**: `"ข้าวมันไก่ผสมไก่ทอด"` หรือ `"ชาเขียวนมหวานน้อย"`
* **ผลลัพธ์ที่คาดหวัง**: บอทตอบกลับการ์ดสีส้มสวยงามพร้อมค่าแคลลอรี่ที่เหมาะสม และมีข้อมูลถูกบันทึกสำเร็จลงใน Google Sheet แผ่นงาน `MealLogs`

### 2. การพิมพ์มั่ว / ข้อความไร้ความหมาย (Gibberish Test)
* **ข้อความทดสอบ**: `"skjfdf"` หรือ `"asdfghjkl"`
* **ผลลัพธ์ที่คาดหวัง**: บอทตอบกลับเป็นข้อความปกติแนะนำให้ระบุชื่อเมนูอาหาร/เครื่องดื่ม และ **ไม่มีการบันทึกแถวข้อมูลใหม่ลงใน Google Sheet แผ่นงาน `MealLogs`**

### 3. การชวนคุยทั่วไป / คำทักทาย (Casual Conversational Test)
* **ข้อความทดสอบ**: `"สวัสดีครับบอท"` หรือ `"วันนี้อากาศดีจัง"`
* **ผลลัพธ์ที่คาดหวัง**: บอทตอบกลับทักทายอย่างเป็นมิตรพร้อมแนะนำให้เริ่มพิมพ์เมนูอาหาร และ **ไม่มีการบันทึกแถวข้อมูลใหม่ลงใน Google Sheet แผ่นงาน `MealLogs`**
