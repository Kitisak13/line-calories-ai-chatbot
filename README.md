# LINE Calories AI Chatbot 🤖🍽️

บอท LINE ช่วยประมวลผล วิเคราะห์ และบันทึกพลังงานแคลลอรี่ของมื้ออาหารส่วนตัวของคุณ ขับเคลื่อนด้วย **Google Gemini API** และจัดเก็บฐานข้อมูลโภชนาการลง **Google Sheets** แยกประวัติผู้ใช้รายคนผ่าน LINE User ID พร้อมแสดงผลผลการคำนวณและข้อมูลสุขภาพอย่างสวยงามผ่าน **LINE Flex Messages** พรีเมียม!

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1.  **AI Calorie Analyzer**: ประมวลผลจากรูปประโยคภาษาไทยและอังกฤษได้อย่างชาญฉลาด วิเคราะห์จำนวนแคลลอรี่อาหารทันทีด้วย **Google Gemini API** 
2.  **Google Sheets Database**: บันทึกรายการโภชนาการเรียลไทม์ลง Google Sheets เป็นฐานข้อมูลหลัก ระบุวันเวลาเป็นเขตเวลาประเทศไทย (Asia/Bangkok Time)
3.  **User ID Tracking**: ระบุตัวผู้ถามอย่างแม่นยำด้วยการกรองประวัติจาก LINE User ID ทำให้ระบบสามารถแยกแยะข้อมูลของแต่ละบัญชีได้อย่างปลอดภัย
4.  **Today's Calories Summary**: คำนวณสรุปแคลลอรี่สะสมรวมประจำวัน (`SUM(Calories)`) และลิสต์เมนูอาหารทุกมื้อที่ทานไปในวันนั้นอย่างประณีต
5.  **Premium LINE Flex Messages UI**: การตอบกลับผ่านการ์ดกล่องข้อความพรีเมียมสีสันสวยงามและแถบสีไดนามิกตามช่วงแคลลอรี่:
    *   🟢 **สีเขียว (แคลรวมต่ำกว่า 1,500 kcal)**: พลังงานดีและเหมาะสม ทานได้อีก
    *   🟠 **สีส้ม (แคลรวม 1,500 - 2,000 kcal)**: พลังงานเกือบเต็มพิกัด แนะนำให้ใส่ใจสุขภาพ
    *   🔴 **สีแดง (แคลรวมเกิน 2,000 kcal)**: คำเตือนสีแดงสด แนะนำเมนูเบาๆ หรือออกกำลังกายเพิ่ม
6.  **Interactive Quick Actions**: มีปุ่มกดด่วนใต้การ์ดผลลัพธ์ เพียงจิ้มบุ่ม **"📊 สรุปแคลรวมวันนี้"** บอทจะสรุปประวัติกลับมาทันทีโดยไม่ต้องเสียเวลาพิมพ์เอง
7.  **Email Debugging Agent**: ระบบรายงานปัญหาฉุกเฉินทางอีเมล หากเกิดข้อผิดพลาดในการประมวลผลหรือข้อบกพร่องใน Google Sheet ระบบจะส่งบันทึกการทำงาน (Debug Logs) ตรงสู่อีเมลผู้พัฒนาทันทีเพื่อแก้ปัญหาได้อย่างรวดเร็ว

## 🛠️ ขั้นตอนการติดตั้งและตั้งค่าระบบ (Setup Instructions)

### 1. การเตรียมระบบฐานข้อมูล Google Sheets
1.  สร้าง Google Sheet ใหม่ 1 ไฟล์
2.  ตั้งชื่อแท็บชีตแรกว่า **`MealLogs`**
3.  ใส่ชื่อหัวตารางในแถวที่ 1 (คอลัมน์ A ถึง E) ตามลำดับ:
    *   คอลัมน์ A: `Timestamp` *(วันและเวลาที่ทำรายการ)*
    *   คอลัมน์ B: `Date` *(วันที่เฉพาะรูปแบบ yyyy-MM-dd)*
    *   คอลัมน์ C: `UserID` *(LINE User ID ของผู้ใช้)*
    *   คอลัมน์ D: `FoodMenu` *(เมนูอาหารที่พิมพ์)*
    *   คอลัมน์ E: `Calories` *(แคลลอรี่ที่แปลงเป็นตัวเลข)*
4.  คัดลอก **Spreadsheet ID** จาก URL ของไฟล์ Google Sheet

### 2. การฝังโค้ดบน Google Apps Script
1.  เปิดระบบ [Google Apps Script](https://script.google.com/)
2.  คัดลอกโค้ดทั้งหมดในไฟล์ `Code.gs` ไปบันทึกทับใน Apps Script Editor
3.  กด **Save**
4.  ไปที่ปุ่ม Dropdown รันด้านบน เลือกฟังก์ชัน **`testSheetAccess`** แล้วกด **Run (เรียกใช้)**
5.  **สำคัญ 🌟**: กดยินยอมรับสิทธิ์ในการเข้าถึงและแก้ไขชีต (Authorization Required) ผ่านเมนู "ตรวจสอบสิทธิ์" จนกว่าคำสั่งรันจะเสร็จสิ้น และมีแถวทดสอบปรากฏขึ้นใน Google Sheet ของคุณ

### 3. การกรอกตัวแปรสภาพแวดล้อม (Script Properties)
เข้าไปที่ **ตั้งค่าโครงการ (สัญลักษณ์รูปฟันเฟือง)** ทางซ้ายมือ เลื่อนลงมาที่หมวด **Script Properties** แล้วกรอกค่าเหล่านี้:
*   `GOOGLE_SHEET`: ไอดีของ Google Sheet ที่คัดลอกมา
*   `GEMINI_API_KEY`: API Key สำหรับใช้งานปัญญาประดิษฐ์ Google Gemini API
*   `LINE_CHANNEL_ACCESS_TOKEN`: Channel Access Token จาก LINE Developers Console

### 4. การเผยแพร่ Web App (Deployment)
1.  คลิกปุ่ม **Deploy (การทำงานใช้จริง)** ขวาบน -> เลือก **New deployment (การทำงานใช้จริงรายการใหม่)**
2.  เลือกประเภทการทำงานเป็น **Web app (เว็บแอป)**
    *   **Execute as**: Me *(อีเมลของคุณ)*
    *   **Who has access**: Anyone *(ทุกคน)*
3.  กด **Deploy** จากนั้นทำการคัดลอก **Web app URL** ที่ระบบสร้างให้
4.  นำ URL นี้ไปใส่ในช่อง **Webhook URL** ในระบบตั้งค่า Messaging API ของ LINE Developers Console และอย่าลืมกดเปิด **Enable Webhook** ด้วยนะครับ!
